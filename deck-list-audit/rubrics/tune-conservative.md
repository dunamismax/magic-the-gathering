# Conservative tuning rubric

Use when the user asks for only the best, clear, conservative, high-impact, or
minimal changes.

- Reconstruct and validate the exact current list first.
- Preserve deck identity, stated experience, locked cards, Rule Zero context,
  combo policy, budget, and Game Changer maximum.
- Recommend the smallest defensible equal Adds/Cuts package, no more than five
  swaps and fewer when appropriate.
- Stop at sidegrades. A cut must be clearly weaker, redundant, unreliable,
  inefficient, or misaligned in this particular deck.
- Screen the entire post-swap list for new deterministic lines and social-risk
  changes, then rerun every hard validation.
- Present the complete actionable package in one Moxfield-ready fenced block,
  one `1 Card Name` per line, with rationale outside the block.
- If no material improvement exists, say so.
