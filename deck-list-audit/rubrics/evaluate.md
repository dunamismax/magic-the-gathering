# Full exact-list evaluation rubric

Use for a complete deck evaluation. Evaluate the submitted list rather than the
commander generically.

1. Run deterministic validation and disclose snapshot dates.
2. Identify primary/secondary strategies, commander dependence, engines,
   closing plans, and early/mid/late development.
3. Count overlapping functional roles using structured annotations plus manual
   deck-context review: lands, land-capable cards, ramp, fast mana, reduction,
   selection, sustained draw, tutors, recursion, spot removal, countermagic,
   wipes, protection, graveyard interaction, stack interaction, win conditions,
   combo pieces, and modal cards.
4. Audit infinite/deterministic lines, finite explosions, locks, denial, and
   repetitive tutor/recursion patterns. State required cards, result,
   commander dependence, independent usefulness, assembly support, earliest
   plausible turn, and disruption points.
5. Separate technically earliest, strong-draw, realistic uncontested, and
   realistic interactive closing windows. Do not invent simulation results.
6. Score power, ceiling, speed, consistency, resilience, interaction, cards,
   mana efficiency, closing, recovery, commander independence, replayability,
   complexity, threat perception, and salt. Do not mechanically average them.
7. Assign one official bracket with lean, play-up/play-down guidance, and a
   concise Rule Zero script. Game Changer count alone is never dispositive.
8. If tuning was requested, use the conservative rubric unless the user asks
   for structural rebuilding.

Finish with audit confidence and unresolved evidence limitations.
